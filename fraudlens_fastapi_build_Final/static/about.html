About this project

Built by Aryan Nagar — final-year B.Tech CSE, Global Institute of Technology (GIT), Jaipur.

Why FraudLens

Employment scams are getting harder to spot by reading alone — scammers now write postings that read almost exactly like real ones. Cybercrime reports on India's National Cyber Crime Reporting Portal rose from under 0.5 million in 2021 to roughly 2.27 million in 2024, with job-related scams consistently among the top categories. Most existing detection systems treat this purely as a text classification problem and return one label with no way for a job seeker to interrogate it. FraudLens was built to close that gap: combine structural signals with text, explain every flag in plain English, and give two separate scores instead of one verdict.

What's under the hood

A LinearSVC classifier trained on EMSCAD (17,880 postings) with TF-IDF text features and metadata, selected over Naive Bayes, Logistic Regression, Random Forest, and XGBoost on fraud-class F1-score. A SHAP explainability layer feeds a Groq-hosted LLM (via LangChain) that turns raw feature attributions into plain-English reasoning. An independent rule-based scam-keyword scanner, live company verification through OpenCorporates and Tavily, and a FastAPI backend serving this custom frontend. See How it works for the full pipeline breakdown.

Background

This started as a college synopsis project and was carried through a full build: data cleaning and feature engineering, five-model comparison, the SHAP + LLM explainability layer, live verification integration, an initial Streamlit deployment, and this current custom FastAPI + HTML/CSS/JS rebuild.
